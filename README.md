# Los Santos Custom · app Windows

Distribuzione ufficiale degli eseguibili Windows del gestionale Los Santos Custom.

Scarica l’installer dalla release più recente. Gli aggiornamenti successivi si controllano dal pulsante **Aggiornamenti** nell’app; l’installazione richiede conferma e chiude il cartellino prima di proseguire. Per mantenere accesso Discord e bozze, aggiorna con l’installer senza disinstallare il programma.

Il repository contiene esclusivamente eseguibili, note di rilascio e il manifest firmato per gli aggiornamenti. Non contiene codice sorgente privato, credenziali o documenti del personale.

I dati operativi rimangono nel database del gestionale: https://gestionale.lscdip.it
